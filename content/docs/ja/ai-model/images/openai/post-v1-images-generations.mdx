与指定のプロンプトに基づいて画像を作成します。[詳細はこちら](https://platform.openai.com/docs/guides/images)。

## クイックスタート

この汎用インターフェースは OpenAI の画像モデルに使用されます。プロジェクト内の GPT Image 2、通用同期生図、Imagen も `/v1/images/generations` を再利用し、対応するモデルページでモデル拡張パラメータを選択します。

| タイプ | モデル |
| --- | --- |
| OpenAI | `dall-e-2`、`dall-e-3`、`gpt-image-1`、`gpt-image-1-mini`、`gpt-image-1.5`、`chatgpt-image-latest` |
| GPT Image 2 | `gpt-image-2`、`gpt-image-2-vip`、`gpt-image-2-1k`、`gpt-image-2-2k`、`gpt-image-2-4k` |
| 通用同期生図 | `z-image`、`z-image-turbo`、`qwen-image`、`wan2.6`、`wan2.7-image`、`wan2.7-image-pro` |
| Imagen | `imagen-4.0-generate-001`、`imagen-4.0-ultra-generate-001`、`imagen-4.0-fast-generate-001` |
| Gemini 画像チャット | `gemini-2.0-flash-exp-image-generation`、`gemini-2.0-flash-exp`、`gemini-2.5-flash-image`、`gemini-3-pro-image-preview`、`gemini-3.1-flash-image-preview` |

```bash
curl "$BASE_URL/v1/images/generations" \
  -H "Authorization: Bearer $NODEKEY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "赤いマウンテンバイクの製品ポスター、白い背景、クリアなスタジオ撮影",
    "size": "1024x1024",
    "quality": "medium",
    "n": 1,
    "response_format": "url"
  }'
```

```python
from openai import OpenAI

client = OpenAI(api_key="sk-xxx", base_url="https://nodekey.xinghanyun.cn/v1")
image = client.images.generate(
    model="gpt-image-2",
    prompt="赤いマウンテンバイクの製品ポスター、白い背景、クリアなスタジオ撮影",
    size="1024x1024",
    quality="medium",
    n=1,
)
print(image.data[0].url)
```

画像編集は `/v1/images/edits` を使用します。通用編集モデルには `qwen-image-edit`、`qwen-image-edit-max`、`qwen-image-edit-plus` およびその日付バージョンが含まれます。Gemini 画像チャットモデルは `/v1/chat/completions` または Gemini ネイティブ `generateContent` を使用します。
