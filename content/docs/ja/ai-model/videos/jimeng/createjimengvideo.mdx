即夢公式 API フォーマットの動画生成インターフェース。

Action パラメータを使用して操作タイプを指定することをサポートしています：
- `CVSync2AsyncSubmitTask`: 動画生成タスクを提出
- `CVSync2AsyncGetResult`: タスク結果を取得

クエリパラメータに Action と Version を指定する必要があります。
