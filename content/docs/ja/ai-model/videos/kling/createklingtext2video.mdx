Kling 可灵フォーマットを使用して、テキスト記述から動画を生成します。

```bash
curl "$BASE_URL/kling/v1/videos/text2video" \
  -H "Authorization: Bearer $NODEKEY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model_name": "kling-v1",
    "prompt": "清晨山路上的骑行者缓慢经过镜头",
    "aspect_ratio": "16:9",
    "duration": "5",
    "mode": "std"
  }'
```
