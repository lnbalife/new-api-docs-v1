## OpenAI ビデオ呼び出し

この一般的なエンドポイントは現在 `sora-2`、`sora-2-pro` に使用されています。作成後は `GET /v1/videos/{task_id}` を使用してクエリし、ビデオファイルのプロキシアドレスは `GET /v1/videos/{task_id}/content` です。

```bash
curl "$BASE_URL/v1/videos" \
  -H "Authorization: Bearer $NODEKEY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "sora-2",
    "prompt": "手持ちカメラが朝のカフェを通り抜け、日差しが窓からテーブルを照らす",
    "seconds": "5",
    "size": "1280x720"
  }'

curl "$BASE_URL/v1/videos/task_xxx" \
  -H "Authorization: Bearer $NODEKEY_API_KEY"
```

フォームアップロードの参考入力もサポートされています；参考画像には `input_reference` を使用します。`sora-2` は `720x1280`、`1280x720` をサポートし、`sora-2-pro` は追加で `1792x1024`、`1024x1792` をサポートします。
