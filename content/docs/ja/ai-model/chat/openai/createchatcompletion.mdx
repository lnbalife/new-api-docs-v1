会話履歴に基づいてモデルの応答を生成します。ストリーミングおよび非ストリーミングの応答をサポートしています。

OpenAI Chat Completions APIと互換性があります。


## マルチモーダルの説明

`messages[].content` にはコンテンツの配列を渡すことができます。アイテム構造は `text`、`image_url`、`input_audio`、`file`、`video_url`をサポートしており、実際に使用可能なモードは選択したモデルとチャネルの能力に依存します。

```bash
curl "$BASE_URL/v1/chat/completions" \
  -H "Authorization: Bearer $NODEKEY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o",
    "messages": [{
      "role": "user",
      "content": [
        {"type": "text", "text": "この画像の商品の売りポイントを説明してください"},
        {"type": "image_url", "image_url": {"url": "https://example.com/product.jpg"}}
      ]
    }]
  }'
```

Geminiのネイティブマルチモーダル呼び出しは `/v1beta/models/{model}:generateContent` を使用します。Geminiの画像生成モデルは、このインターフェースのOpenAIチャットフォーマットを介しても呼び出すことができます。
