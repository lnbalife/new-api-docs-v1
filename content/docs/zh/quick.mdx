## 第一步：获取 API 密钥

在 NodeKey 控制台注册并生成您的唯一 API 密钥(令牌)。


## 第二步：集成

如果您已经在使用 OpenAI SDK，只需更改基础 URL 即可。

<Tabs items={['Python', 'Node.js', 'Curl']}>
  <Tab value="Python">
    ```python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_NODEKEY_KEY",
    base_url="https://nodekey.xinghanyun.cn/v1"
)

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "Hello!"}]
)
    ```
  </Tab>
  <Tab value="Node.js">
    ```ts
import OpenAI from "openai";

const client = new OpenAI({
    apiKey: "YOUR_NODEKEY_KEY",
    baseURL: "https://nodekey.xinghanyun.cn/v1"
});

const completion = await client.chat.completions.create({
    model: "gpt-4o",
    messages: [{ role: "user", content: "Hello!" }],
});
    ```
  </Tab>
  <Tab value="Curl">
    ```bash
curl -X POST "https://nodekey.biandianyun.com/v1/chat/completions" \
  -H "Authorization: Bearer YOUR_NODEKEY_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o",
    "messages": [
      {
        "role": "user",
        "content": "Hello!"
      }
    ]
  }'
    ```
  </Tab>
