根据对话历史创建模型响应。支持流式和非流式响应。

兼容 OpenAI Chat Completions API。


## 多模态说明

`messages[].content` 可传内容数组。项目结构支持 `text`、`image_url`、`input_audio`、`file`、`video_url`，实际可用模态取决于所选模型与渠道能力。

```bash
curl "$BASE_URL/v1/chat/completions" \
  -H "Authorization: Bearer $NODEKEY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o",
    "messages": [{
      "role": "user",
      "content": [
        {"type": "text", "text": "描述这张图里的商品卖点"},
        {"type": "image_url", "image_url": {"url": "https://example.com/product.jpg"}}
      ]
    }]
  }'
```

Gemini 原生多模态调用使用 `/v1beta/models/{model}:generateContent`。Gemini 图片生成模型还可通过本接口的 OpenAI 聊天格式调用。
