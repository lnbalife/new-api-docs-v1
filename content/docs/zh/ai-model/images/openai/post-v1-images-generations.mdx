          curl "$BASE_URL/v1/images/generations" \
            -H "Authorization: Bearer $NODEKEY_API_KEY" \
            -H "Content-Type: application/json" \
            -d '{

              "prompt": "一张红色山地自行车的产品海报，白色背景，清晰棚拍",

          from openai import OpenAI


          client = OpenAI(api_key="sk-xxx",

## 快速上手

该通用接口用于 OpenAI 图像模型；项目内的 GPT Image 2、通义同步生图和 Imagen 也复用 `/v1/images/generations`，按对应模型页选择模型扩展参数。

| 类型 | 模型 |
| --- | --- |
| OpenAI | `dall-e-2`、`dall-e-3`、`gpt-image-1`、`gpt-image-1-mini`、`gpt-image-1.5`、`chatgpt-image-latest` |
| GPT Image 2 | `gpt-image-2`、`gpt-image-2-vip`、`gpt-image-2-1k`、`gpt-image-2-2k`、`gpt-image-2-4k` |
| 通义同步生图 | `z-image`、`z-image-turbo`、`qwen-image`、`wan2.6`、`wan2.7-image`、`wan2.7-image-pro` |
| Imagen | `imagen-4.0-generate-001`、`imagen-4.0-ultra-generate-001`、`imagen-4.0-fast-generate-001` |
| Gemini 图片聊天 | `gemini-2.0-flash-exp-image-generation`、`gemini-2.0-flash-exp`、`gemini-2.5-flash-image`、`gemini-3-pro-image-preview`、`gemini-3.1-flash-image-preview` |

```bash
curl "$BASE_URL/v1/images/generations" \
  -H "Authorization: Bearer $NODEKEY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "一张红色山地自行车的产品海报，白色背景，清晰棚拍",
    "size": "1024x1024",
    "quality": "medium",
    "n": 1,
    "response_format": "url"
  }'
```

```python
from openai import OpenAI

client = OpenAI(api_key="sk-xxx", base_url="https://nodekey.xinghanyun.cn/v1")
image = client.images.generate(
    model="gpt-image-2",
    prompt="一张红色山地自行车的产品海报，白色背景，清晰棚拍",
    size="1024x1024",
    quality="medium",
    n=1,
)
print(image.data[0].url)
```

图片编辑走 `/v1/images/edits`；通义编辑模型包含 `qwen-image-edit`、`qwen-image-edit-max`、`qwen-image-edit-plus` 及其日期版本。Gemini 图片聊天模型走 `/v1/chat/completions` 或 Gemini 原生 `generateContent`。
