## OpenAI 视频调用

该通用入口当前用于 `sora-2`、`sora-2-pro`。创建后使用 `GET /v1/videos/{task_id}` 查询，视频文件代理地址为 `GET /v1/videos/{task_id}/content`。

```bash
curl "$BASE_URL/v1/videos" \
  -H "Authorization: Bearer $NODEKEY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "sora-2",
    "prompt": "手持镜头穿过清晨的咖啡店，阳光从窗边扫过桌面",
    "seconds": "5",
    "size": "1280x720"
  }'

curl "$BASE_URL/v1/videos/task_xxx" \
  -H "Authorization: Bearer $NODEKEY_API_KEY"
```

也支持表单上传参考输入；参考图使用 `input_reference`。`sora-2` 支持 `720x1280`、`1280x720`，`sora-2-pro` 额外支持 `1792x1024`、`1024x1792`。
