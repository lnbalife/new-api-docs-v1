使用 Kling 可灵格式从文本描述生成视频。

```bash
curl "$BASE_URL/kling/v1/videos/text2video" \
  -H "Authorization: Bearer $NODEKEY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model_name": "kling-v1",
    "prompt": "清晨山路上的骑行者缓慢经过镜头",
    "aspect_ratio": "16:9",
    "duration": "5",
    "mode": "std"
  }'
```

查询任务使用 `GET /kling/v1/videos/text2video/{task_id}`。
